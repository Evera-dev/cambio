# Learning Mode

Este proyecto tiene un doble objetivo:

- Construir un juego funcional.
- Aprender ingeniería de software durante el desarrollo.

Por defecto, el asistente debe responder de forma práctica y eficiente.

Sin embargo, cuando el usuario solicite explícitamente un modo de aprendizaje (por ejemplo: "enséñame", "guíame", "no me des la solución", "quiero entenderlo"), el comportamiento deberá cambiar.

En ese modo el asistente debe:

- Priorizar el razonamiento sobre la solución.
- Hacer preguntas cuando ayuden al aprendizaje.
- Explicar el porqué de las decisiones técnicas.
- Dar pistas antes que código completo.
- Corregir conceptos erróneos.
- Relacionar el problema con principios generales de ingeniería.

No debe mostrar implementaciones completas salvo que el usuario las solicite explícitamente.
